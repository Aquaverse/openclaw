# Comparison mode

Use when the user asks to compare variants, choose between them, or judge a redesign. Apply the main skill's evidence and grounding rules. Read the rubric before scoring.

## Compare

1. Establish the shared task and stated constraints. When missing context would change the verdict, identify it and use an explicit assumption or ask a targeted question.
2. For each artifact with sufficient evidence, give a score and one sentence explaining the repair-scope band, using a common inspected scope where possible. Mark unscorable artifacts as “insufficient evidence” and identify what is missing. Disclose differing scopes. A comparison of readable artifacts may be useful, but label it as partial; withhold a verdict about the full set while any contender remains unassessed.
3. Select up to five shared, task-relevant dimensions, fewer when evidence is limited. Show facts for each artifact; explain evaluative differences with relevant principles or verified sources. A defect in only one variant is valid comparative evidence on a shared dimension.
4. Give a recommendation supported by the dimensions. A row may favor one or several variants, tie, or remain unknown. Retain ties that establish a meaningful shared strength or defect; omit dimensions that add nothing to the decision.

## Verdict

Choose a winner when there is a material, supported advantage. Otherwise state “no material difference observed” or “insufficient evidence,” with deciding evidence or the test needed. For tradeoffs, give a conditional recommendation with explicit assumptions; combining specific parts from multiple variants is also valid. Do not manufacture differences between identical artifacts.

For a redesign, explicitly say improved, regressed, mixed, unchanged within inspected scope, or insufficient evidence. Describe the change from before to after.

Identify a constraint that could change a conditional verdict when one exists. A universal “fact that flips the call” is not required. Close with zero to three material fixes in the recommended variant using Before/After/Why. When no winner exists, a common blocker can still be identified; no fix list is required.

## Presentation

Preserve user labels and presentation order; keep before ahead of after. For an unlabeled composite image, use left-to-right then top-to-bottom order and state that mapping. Order is a reading aid, not quality evidence.

A compact table works for two or three variants:

| Dimension                 | A      | B      | Assessment and basis                             |
| ------------------------- | ------ | ------ | ------------------------------------------------ |
| <task-relevant dimension> | <fact> | <fact> | <edge/tie/unknown, with principle if evaluative> |

For larger sets or a narrow pane, use one row per artifact and shared dimension columns, or grouped sections with identical dimensions. Assess every artifact; there is no fixed five-artifact cutoff or score-based elimination. When the set cannot be inspected reliably, state the limit and request a subset or inspect clearly identified batches before an overall verdict.

Include each artifact's score and band rationale, or its explicit “insufficient evidence” status; the inspected scope; the shared comparison; the verdict and its basis; and necessary assumptions or next evidence. Do not substitute separate full critiques for the requested comparison.
