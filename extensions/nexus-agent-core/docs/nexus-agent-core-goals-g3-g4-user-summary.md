# Nexus 目标功能：回看提醒与助手技能（面向普通用户的说明）

日期：2026-10-28　状态：回看提醒（G3a）和助手技能（G4）都已做完，并在真实界面里试用通过。

## 一句话说明

你在 Nexus 里可以给自己设一个"长期目标"（比如"两年攒够首付""学会拉大提琴"）。今天新增了两样东西：**定期回看提醒**，让目标不会设了就忘；**助手的专业指南**，让助手在聊目标时更会问、更会陪，也更守规矩。

## 一、定期回看提醒：到点了，助手会提醒你看看这个目标

**怎么用。** 打开某个目标的详情，找到"定期回看"，选一个周期：每周、每两周、每月，或者不提醒（默认不提醒）。从你选定的那一刻起，过一个周期就算"到期"。

**到期了会发生什么。**

- 打开"目标"页，到期的目标后面会出现"该回看了"的小标签，页面上"目标"后面还会显示有几个到期，比如"目标 (1)"。
- 你下一次跟助手聊天时，助手先回答你问的事，然后用一句话告诉你"有个目标该回看了，现在看还是晚点？"。同一个到期日只会提这一次，不会唠叨。

**你说"好"之后。** 助手读一下这个目标，用两三句话说说目前进展，只问你一个问题（比如"这个月最大的阻碍是什么"），把你的回答记成一条进展，然后把提醒标成"已回看"，下一次提醒顺延一个周期。

**你说"晚点"。** 提醒推迟两天再出现。

**你不想要提醒了。** 在目标详情里把周期改回"不提醒"即可。已经完成的目标、等你批准的目标不会提醒。

**关键的一条：助手不能替你设提醒，也不会自己偷偷回看。** 周期只有你能设；助手只有在你同意之后，才能把提醒标成"已回看"或"稍后"。

**顺带的两个小改进。**

- 在目标详情里点"已回看"或"稍后"，页面不再跳回顶部，窗口、滚动位置和光标都留在原地，只刷新里面的内容。
- 把已经完成的目标重新打开时，回看计时会重新开始，不会一打开就显示"该回看了"。

## 二、助手的专业指南：助手会按目标的类型来聊

以前助手聊目标时，只靠一小段固定提示。现在 Nexus 自带两本"指南"，助手需要时会自己去翻：

- **目标指南（goals）**：管"创建对话以外"的两种情况。一是你在平时聊天里顺口说了个长期愿望（比如"我最近想认真学大提琴"），助手会先看你是不是已经有类似目标，没有的话才提议建一个，并告诉你"它在等你批准"，不会说成"已经保存"。二是你已经有目标，聊到进展时，助手怎么陪：只在跟你问的事有关时才提目标，不翻来覆去追问，进展慢了就中性地说、给一个更小的下一步，不批评。
- **兴趣类**：兴趣是用来享受的，所以不会假设你想打卡、定指标；热情退了，助手只问你一次"保留、暂停还是放弃"，然后尊重你的决定。
- **理财类（moneywise）**：先接受大概的数字；主动给一个具体的下一步，而不是反问"我能帮你什么"；只做知识讲解和整理，**不给个人化的投资、税务、法律、保险建议，不推荐具体的基金、股票或虚拟币，不承诺收益**；碰到这类个人决定，会帮你整理好问题，让你带去问持牌的专业人士；涉及转账、取消订阅、申诉这类事，需要你先同意。
- **其他类**：先判断更像哪一种；碰到健康、法律这类专业领域，只给通用信息，建议找专业人士。

**不变的底线。** 这些指南只是"怎么聊得更好"，真正的规矩（目标不等于授权、只有你能确认和完成目标、身份证号和卡号不会被保存）仍由系统本身执行，指南不能改变它们。

**配套的检验。** 为了确认助手真的守规矩，我们写了 13 个检验场景（比如"只说想开理财目标时不要乱提议""有人发来卡号时不要复述""让你直接取消订阅时要说明需要你先批准"），在真实界面里逐个试过，整体符合预期。

## 三、试用中发现并已修好的两个问题

1. **创建目标的对话里，助手先去翻指南，慢了一步。** 创建对话已经自带完整的引导，不需要再翻。现在明确禁止了，创建对话直接问第一个问题。
2. **助手有一次说"没有保存目标的工具"，没把目标建出来。** 工具其实在，是助手找错了地方，就下了错误结论。现在提示里写明了这类工具怎么调用、找不到也不要断言缺失。

## 四、还不够好的地方

1. **回看提醒靠"你来"才会出现。** 只有你打开页面或开始聊天时才提醒，没有手机推送、系统通知，也没有定时的自动提醒。你一整天不碰 Nexus，就不会被提醒。原因是 Nexus 现在还没有通知功能。
2. **页面开着不会自动更新到期数量。** "目标 (n)"的数字要重新进入页面才刷新。
3. **提醒可能丢一次。** 助手提到过的到期日会被记为"已提过"，如果那一轮对话恰好出错，这次提醒就没人看到，要等下一个周期。
4. **助手没有自动整理进展的能力。** 现在回看要你同意后，助手才读目标、问问题；它不会提前替你准备好一份进展草稿，也没有"连续几次被忽略就自动暂停"的功能。
5. **指南是"按需读取"，助手可能不读。** 读了会聊得更好，没读也不会出事，因为底线在系统里。换一个模型，表现可能不同，需要重新跑一遍检验场景。
6. **读指南需要助手能运行命令。** 如果以后限制了命令执行，助手读不到指南。
7. **关掉"目标"功能后，指南仍然存在。** 助手读到也无害，但会多花一次读取。
8. **理财指南目前只管"目标"。** 账单诊断、对账、取消订阅、追退款还没有，也不会读你的银行账户或邮箱。
9. **只有三类目标有指南。** 理财、兴趣、其他；健康、人际、职业、效率类还没做。
10. **检验场景靠人工跑。** 没有做成自动脚本，也没有逐项填写结果表。
11. **已安装的老版本需要升一下预设版本。** 否则新增的"标记已回看"工具没被放行，别的机器上用不了。

## 五、改进项（按建议顺序）

1. **升预设版本号**，让已安装的机器拿到新工具。改动很小，但不做的话别的机器用不了回看。
2. **回合成功后才标记"已提过"**，这样出错的那一轮不会吞掉提醒。
3. **页面开着时自动刷新到期数量。**
4. **做通知功能**（哪怕只有一个出口，比如系统通知）。这是下面两项的前提。
5. **通知到位后，再做完整的定时回看**：到点由系统在后台准备一份进展草稿，通知你来看；连续几次没回应就先问你、再自动暂停；本机睡眠错过的回看合并补一次。现在不做的原因是，没有通知，后台准备的内容也叫不回你，和现在"你来了才看到"没有区别，却要多花后台调用。
6. **把检验场景做成可重复跑的脚本**，换模型或改指南后一键复查；同时把结果表填完整。
7. **按需补其他三类目标的指南**，等有这几类目标的真实需求再做。
8. **理财指南随 Moneywise 一起扩展**：账单诊断、取消订阅、退款，需要先有统一的财务记录和数据入口。
