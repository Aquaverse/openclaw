# Nexus 使用指南（面向普通用户的开通与连接流程）

> 状态：草案 v0.1（2026-10-29）。这是按 [部署方案](./nexus-agent-core-deployment-plan.md) 设计的**预期使用流程**；页面文案和按钮名称在 portal 开发时可能调整，文中【待验证】项见部署方案第 16 章。服务地址以 `a.b.com` 为例。

## 1. 你会得到什么

注册成功后，服务器上会为你单独开一个 Nexus 助手实例，只属于你一个人。它在服务器上持续运行（你关掉电脑、手机，它的定时回检和后台任务也照常进行），自带一个服务器端的浏览器，用来替你查资料、办事。

你可以用三种方式找它：

1. **远程访问**：用 Mac App 或网页控制台连接，查看事项、审批决策、管理文件和目标；
2. **Telegram**：在 Telegram 里给你自己的 bot 发消息；
3. **WhatsApp**：在 WhatsApp 里给一个专用号码发消息。

三种方式彼此独立，**只用远程访问也完全可以**；Telegram 和 WhatsApp 是为了随时随地能在聊天软件里给助手下达指令、收到结果。

## 2. 开通账号

目前通过邀请码注册。

1. 向管理员要一个**邀请码**（一次性或限次数，有有效期）。
2. 打开 `https://a.b.com/`，填写邮箱、密码（建议 12 位以上）和邀请码，点"注册"。
3. 页面显示"正在为你开通…"，通常 **30–90 秒**。完成后自动进入"连接"页。
4. 如果提示"当前名额已满"，说明服务器资源暂时用完，邀请码不会被扣次数，稍后再试或联系管理员。

## 3. "连接"页上有什么

- **你的实例地址**：`https://a.b.com/t/<你的编号>/`
- **访问口令（token）**：默认隐藏，点"显示"并再次输入登录密码后可见。它相当于你这个实例的钥匙，**不要发给别人、不要贴到聊天或截图里**。
- **打开网页控制台**按钮。
- Telegram、WhatsApp 的绑定入口和当前状态。
- 实例状态（运行中 / 已停止 / 异常）、重启按钮。

## 4. 方式一：远程访问

### 4.1 网页控制台

点"打开网页控制台"，或直接访问你的实例地址，按提示粘贴 token 即可。你可以在这里看到 Nexus 的事项、决策、证据、偏好、文件和目标。

### 4.2 Mac App

> 需要使用"纯客户端"版本的 Mac App（不再自带本地网关）。该构建正在规划中，在它发布前，现有安装包会先装一个本地网关，需要再手动改连远程。系统要求 macOS 15 或更高。

1. 首次启动选择"**连接已有网关**"（已安装的用户：连接 → Gateways → Add Gateway）。
2. 地址填你的实例地址 `https://a.b.com/t/<你的编号>/`。
3. 认证方式选"**Token**"，粘贴 token。（"浏览器登录"在这里不可用。）
4. 第一次连接如果提示"等待批准"，回到 portal 的"设备"列表点"批准"，或在网页控制台里批准。
5. 连上后左侧应能看到 Nexus。

### 4.3 需要你亲自登录某个网站时（接手浏览器）

助手遇到登录、短信验证码、二次验证、人机验证时，会停下来等你。在网页控制台的 **Browser** 面板里，你能看到助手用的那个浏览器并直接操作（可以键入、粘贴）：完成登录后回到对话告诉它继续即可。你离开后助手不会停止，但这类步骤会一直等你。

### 4.4 忘了 token，或怀疑泄露

- 忘了：登录 portal → 连接页 → 显示 token。
- 怀疑泄露：连接页 → "轮换 token"。旧 token 立刻失效，实例会重启一下（十几秒到半分钟），**所有已连接的设备都需要用新 token 重新登录**；Telegram / WhatsApp 连接会自动恢复。

## 5. 方式二：Telegram

你需要先在 Telegram 里创建一个**属于你自己的 bot**（这一步只能你自己做，平台无法代办）。

1. 在 Telegram 搜索 `@BotFather`，发送 `/newbot`，按提示起一个名字和一个以 `bot` 结尾的用户名，它会给你一串 **bot token**。
2. 回到 portal 连接页 → Telegram → "开始绑定"，粘贴 bot token，点"提交"。portal 会验证并显示你的 bot 用户名。
3. 在 Telegram 里搜到你的 bot，发 `/start` 或任意一句话，它会回复一个**配对码**。
4. 把配对码填回 portal，点"确认"（也可以在网页控制台 Settings → Channels 里批准）。
5. 状态变为"已绑定"。再发一句话试试，助手应当回复。

要点：

- **配对的意义**：只有完成配对的这个 Telegram 账号才是你，别人给你的 bot 发消息不会被执行。
- bot token 等同于 bot 的密码。万一泄露，在 `@BotFather` 里对该 bot 用 `/revoke` 重新生成，再回 portal 重新提交即可。
- 需要审批某个动作时，聊天里可能给你按钮；如果出于安全原因不能直接点按钮批准，会给你一个需要登录的网页链接，到那里批准。
- 解绑：连接页 → Telegram → "解绑"，并建议在 BotFather 里吊销旧 token。

## 6. 方式三：WhatsApp

> **先读风险**：WhatsApp 的接入方式是"关联设备"（和在电脑上使用 WhatsApp Web 类似），不是官方企业接口。**号码有被 WhatsApp 限制的可能**。强烈建议使用一个**专用号码**（副号 / eSIM），不要用你的主号；不要用它做群发或联系陌生人。

1. 准备好专用号码和一部登录了该号码 WhatsApp 的手机。
2. portal 连接页 → WhatsApp → "开始绑定"，阅读并勾选风险提示，点"生成二维码"。
3. 在手机 WhatsApp 里：**设置 → 已关联设备 → 关联设备**，扫描页面上的二维码。二维码每隔一小会儿会自动刷新，过期了就点"重新生成"。
4. 连接成功后，用**你自己的个人号码**给这个专用号码发一条消息，会收到配对码；填回 portal 确认。**配对码 1 小时内有效**，同时最多保留 3 个待处理请求。
5. 状态变为"已绑定"。再发一句话试试。

要点：

- 如果在手机上手动"退出关联设备"，或号码被限制，portal 会显示"需要重新扫码"，按步骤 2–3 重新绑定。
- 如果页面提示"请到网页控制台的 Channels 页面扫码"，那是二维码改走控制台的情况，按提示操作即可。
- 解绑：连接页 → WhatsApp → "解绑"（会同时解除手机上的关联设备）。

## 7. 日常使用与管理

| 想做什么         | 在哪里                                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------------------------ |
| 看助手是否在线   | 连接页的实例状态；Telegram / WhatsApp 各有独立状态（"实例在线但通道掉线"是可能的）                     |
| 重启实例         | 连接页 → 重启（几十秒）                                                                                |
| 暂停助手         | 连接页 → 停止。**停止期间助手的定时回检和后台任务都不会运行**；点"启动"恢复                            |
| 换成自己的模型   | 模型页 → "使用自己的 key"，填供应商、地址和 key，会先做一次验证。注意：这把 key 你的助手自己是能看到的 |
| 换回平台默认模型 | 模型页 → "使用平台默认"                                                                                |
| 看用量           | 模型页 → 本月已用 / 预算；预算用完后助手会提示模型不可用，可切自己的 key 或联系管理员                  |
| 看日志           | 连接页 → 查看日志（已隐藏口令类内容）                                                                  |
| 重置实例         | 连接页 → 重置（会清空你的数据并重新开始，通道需要重新绑定），需要输入密码和确认词                      |
| 删除账号         | 设置 → 删除账号：先解除 WhatsApp 关联，数据默认保留 30 天供你反悔，也可选"立即彻底清除"                |

## 8. 常见问题

**打开实例地址是空白页或 502？**
实例可能已停止或正在启动：先看连接页的状态；若是"已停止"点"启动"，若"异常"点"重启"，仍不行就把连接页上的"查看日志"内容发给管理员。

**Mac App 一直连不上？**
检查地址是否带完整路径 `https://a.b.com/t/<编号>/`（含结尾斜杠）、token 是否是最新的（轮换后旧的失效）、是否需要在 portal 的设备列表里批准。

**Telegram 发消息没反应？**
先看 portal 里 Telegram 状态是否"已绑定"；再确认发消息的是完成配对的那个账号；若 bot token 被吊销过，需要重新提交。

**WhatsApp 突然掉线？**
多半是手机侧退出了关联设备，或号码被限制。重新扫码；如果反复被限制，请更换专用号码，并减少消息频率。

**助手在浏览器里卡在登录页？**
在网页控制台的 Browser 面板里亲自完成登录 / 验证码，然后告诉助手继续。

**我的数据存在哪里？**
在服务器上你自己的实例里（事项、证据、偏好、文件柜、目标和对话记录）。其他用户的实例与你相互隔离；运营人员默认不会查看你的数据，确需查看时有审计记录。服务器会做每日加密备份。

## 9. 安全小贴士

- token 和密码不要发给任何人，也不要贴进聊天或截图。
- 使用专用号码连接 WhatsApp；不要把主号绑上去。
- 给助手的指令里，凡是涉及付款、发送、删除等不可逆动作，Nexus 会请你先审批；请认真看清再批准。
- 离开常用设备前，如果设备丢失，到 portal 里"撤销设备"，必要时轮换 token。
